# Function signatures (`research/re/signatures/`)

IDA-style wildcard byte signatures (plus mnemonic hashes) generated by
`scripts/re/fingerprint_functions.py`, so recovered functions can be re-found
across exe versions or in sibling Gamebryo binaries (FO3, Oblivion).

One JSON file per recovered function:

```json
{
  "candidate_name": "EncounterZone::ResolveSpawn",
  "binary_md5": "...",
  "function_va": "0x00842F10",
  "ida_signature": "55 8B EC ?? ...",
  "mnemonic_hash": "..."
}
```

Re-scan a signature against a new binary with Ghidra's
`Search > For Bytes`, rizin `/x ...::...`, or a small capstone script.
