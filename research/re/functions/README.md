# Function notes (`research/re/functions/`)

Ghidra headless dumps land here as `functions.json`, `calls.json`,
`strings.json` (generated by `tools/re/ghidra/postscripts/export_artifacts.py`
via `scripts/re/import_ghidra.py`).

Per-function investigation notes use this template:

```markdown
## 0x00XXXXXX — <candidate name> (confidence 0.xx)

**Evidence:**
- <string xrefs / imports / call sites / record 4CC access>

**Decompiled shape (excerpt):**
<ghidra pseudocode>

**Against:** <counter-evidence, if any>
```

Entries graduate to `../symbols.json` once they have at least three
concordant static signals or one runtime verification.
